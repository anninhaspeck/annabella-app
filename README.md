# 🌸 annabella-app

Aplicativo criativo desenvolvido para integrar e exibir conteúdos do **Pinterest**, unindo inspiração visual e design artístico no estilo **AnnaBella Universe**.  
O objetivo é criar uma experiência leve, estética e interativa para amantes de arte, fotografia e moda.

---

## ✨ Funcionalidades Principais
- 🔗 **Integração com a API do Pinterest** — conecta diretamente aos boards e pins.
- 🖼️ **Galeria dinâmica** — exibe imagens inspiradoras em tempo real.
- 💖 **Favoritos personalizados** — permite salvar pins e coleções preferidas.
- 🎨 **Tema artístico e intuitivo** — interface baseada em tons pastel e estética criativa.
- 📱 **Design responsivo** — adaptado para iOS, iPad e web.

---

## 🧠 Tecnologias Utilizadas
- **Frontend:** HTML5, CSS3, JavaScript  
- **Framework:** React Native *(ou outro, se for o caso)*  
- **API:** Pinterest Developer Platform  
- **Versionamento:** Git e GitHub
