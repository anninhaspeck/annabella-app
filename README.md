# 🌸 AnnaBella App

Aplicativo desenvolvido para integrar e exibir conteúdos do **Pinterest**, com uma experiência leve, estética e interativa — pensada especialmente para criadores de conteúdo, artistas e amantes da inspiração visual.

---

## ✨ Visão Geral

O **AnnaBella App** conecta-se diretamente à **API do Pinterest**, permitindo exibir pins, coleções e tendências em tempo real.  
O design segue o estilo **AnnaBella Universe**: elegante, intuitivo, pastel e responsivo — adaptado para **iPhone, iPad e Web**.

---

## 💡 Funcionalidades Principais

- 🔗 **Integração com API do Pinterest** — conexão direta para exibir imagens, ideias e coleções personalizadas.  
- 🖼️ **Feed dinâmico e inspirador** — atualização automática de pins em tempo real.  
- 💾 **Favoritos e coleções personalizadas** — salve pins e temas do seu interesse.  
- 🎨 **Design estético e intuitivo** — interface baseada em tons suaves, tipografia clean e ícones minimalistas.  
- 📱 **Layout responsivo** — otimizado para iOS, iPadOS e navegadores web.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript  
- **Framework:** React Native *(ou outro framework equivalente, conforme versão)*  
- **API:** Pinterest Developer Platform  
- **Controle de versão:** Git e GitHub
